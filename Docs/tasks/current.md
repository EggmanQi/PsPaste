## 任务四：热键注册失败的可见提示与冲突处理

### 背景

实测发现：当系统已有应用（如 Paste.app，登录项自启）注册了当前热键（⌘⇧`）时，
Carbon `RegisterEventHotKey` 静默失败——当前实现仅 `print` 到控制台，
用户看到的现象是“热键完全无响应、App 像没启动一样”。必须为失败提供
**用户可感知**的提示。

### 范围

1. `HotKeyService.start()` 失败时，通过回调/通知把 `lastError` 暴露给装配层
   （不在 HotKeyService 内直接弹 UI，保持模块边界）。
2. 失败提示（三级，至少做到前两级）：
   - **菜单栏**：状态图标加警示标记（如 `clipboard.badge.exclamationmark` 或红点）；
   - **系统通知**：`UNUserNotificationCenter` 发送通知，说明
     “快捷键 ⌘⇧` 被其他应用占用，P's Paste 无法使用”；
   - **菜单项**：菜单顶部增加“快捷键被占用”禁用项，在 `menuNeedsUpdate` 中刷新。
3. 启动时若注册失败，**每 30s 自动重试一次**（用户可能稍后退出冲突应用），
   重试成功则清除警示状态。重试调度器需要可被测试（注入时钟或抽纯逻辑）。
4. 可选加分项：启动时检测 `NSWorkspace` 中是否有已知占用热键的应用在运行，
   在通知中点名提示。做不了就跳过并说明。
5. 通知权限：首次发送前请求授权；被拒绝时降级为仅菜单栏警示（通知不是必须路径）。

### 验收标准

**A. 开发自检：**

- [ ] 为“失败→重试调度”“失败状态暴露”“通知发送降级”写单测（注入失败/成功序列
  模拟注册结果），`xcodebuild test` 全部通过。
- [ ] Debug 编译 0 error 0 警告。

**B. 人工验证（列出待验证，不得声称已验证）：**

- [ ] 先启动 Paste.app（或占用 ⌘⇧` 的任意应用），再启动 PsPaste →
  菜单栏图标有警示标记 + 收到系统通知。
- [ ] 退出冲突应用后 ≤30s → 警示自动消失，热键可用。
- [ ] 无冲突时启动 → 无任何提示，行为与修复前一致。

## 任务五：面板点击外部自动收起

### 背景与目标

当前面板唤出后只能经热键 toggle 或 Esc 关闭。期望：点击面板以外区域时
面板自动收起，行为对齐 Paste/Maccy。

### 关键机制判断（决定实现方案，勿绕过）

面板是 `.nonactivatingPanel`（ARCH §5），**应用从不激活，因此点击其他应用
不会触发 resignKey/deactivate 通知**——不能用“失去焦点”被动感知，
必须在面板可见期间**主动监听**两类事件：

1. **全局鼠标按下**：`NSEvent.addGlobalMonitorForEvents(matching: .leftMouseDown)`。
   注意：全局监听收不到发往本应用自身的事件（如点自己的菜单栏图标/菜单），
   这正好是期望行为——用菜单时面板不收起。
2. **前台应用切换**：`NSWorkspace.shared.notificationCenter` 订阅
   `didActivateApplicationNotification`——⌘Tab 切应用、点击 Dock 等
   键盘驱动的切换也能覆盖（鼠标监听覆盖不到这些）。

### 范围（改动集中于 PanelController）

1. 可见期生命周期：`show()` 末尾安装两个监听；`close()` 与
   `closeImmediately()` 收起后移除；成对、幂等，不得泄漏。
2. 鼠标监听：`guard panel.isVisible`；`NSEvent.mouseLocation`（屏幕坐标）；
   `!panel.frame.contains(loc)` 时 `close()`。
3. 应用切换：激活应用 bundleID ≠ 本应用且面板可见 → `close()`；
   本应用 activate（如打开调试窗口）不收起。
4. **将“是否应因某事件收起”抽成纯函数**（输入：事件类型 + 位置 + 面板 frame +
   激活应用 bundleID + 本应用 bundleID；输出 Bool），对其写单测；
   监听安装/移除本身留人工验证。

### 验收标准

**A. 开发自检：**

- [ ] `xcodebuild test` 全部通过（含新增纯函数单测：面板内点击不收起、
  面板外点击收起、切到其他应用收起、本应用 activate 不收起）。
- [ ] Debug 编译 0 error 0 警告。

**B. 人工验证（列出待验证，不得声称已验证）：**

- [ ] 唤出面板 → 点击桌面空白区域 → 收起。
- [ ] 唤出面板 → 点击 Safari 内容区 → 收起且 Safari 正常获得焦点。
- [ ] 唤出面板 → ⌘Tab 切应用 → 收起。
- [ ] 唤出面板 → 点击面板内卡片/搜索框 → 不收起。
- [ ] 唤出面板 → 点击菜单栏图标用菜单 → 面板不收起。
- [ ] 反复唤出/收起 10 次行为一致，无监听泄漏迹象。

### 两个任务共同注意

- 任务四的菜单栏警示与任务五的监听共存：警示状态下热键本就无法用，
  面板唤出不受影响（菜单点击仍可打开面板），两者无状态耦合，勿引入共享状态。
- 插桩用的 `print` 一律不留，失败信息走 `lastError`/回调。
