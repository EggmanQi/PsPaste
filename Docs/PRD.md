# P's Paste — 产品需求文档（PRD）

> 状态：MVP 需求已冻结（2026-10-26）。修改本文档需同步更新 `ROADMAP.md` 与相关任务单。
> 参考产品：Paste（pasteapp.io）。本项目为个人自用起步，后续可能差异化商业化。

## 1. 产品定位

轻量级 macOS 剪贴板管理器，采用 **Paste 式底部唤出历史面板** 的交互形态，
以 **本地优先 + iCloud（CloudKit 私有容器）同步** 为持久化方案。

- 对标空位：Maccy 的轻量 + Paste 的底部面板 UI 与 iCloud 同步。
- 当前阶段：**自用 MVP**，不做商业化相关功能（无付费、无账号、无遥测）。
- 商业化预留：UI 视觉层必须可整体替换（见 `UI.md` 与 `ARCHITECTURE.md`）。

## 2. 目标用户与使用场景（当前 = 开发者本人）

| 场景 | 描述 |
|---|---|
| 找回历史复制 | 复制了新内容后，需要找回几分钟/几天前复制的文本、链接、图片 |
| 快速复用 | 通过全局热键唤出底部面板（当前默认 ⌘⇧`，曾用 ⌘⇧V，与 Paste.app 冲突），键盘选择并直接粘贴到当前应用 |
| 常用片段固定 | 把高频片段固定到 Pinboard，随时取用 |
| 跨设备 | 在多台 Mac（及未来 iOS 端）间通过 iCloud 同步历史与 Pinboard |

## 3. MVP 功能范围（必须全部实现才算 MVP 完成）

| # | 功能 | 验收要点 |
|---|---|---|
| F1 | 剪贴板自动捕获 | 复制文本/链接/图片后 ~1s 内出现在历史中；不重复记录相同变更 |
| F2 | 本地持久化 | 重启 App 后历史仍在；历史上限可配置（默认 1000 条），超限自动清理最旧未固定项 |
| F3 | iCloud 同步 | 开启后通过 CloudKit **私有容器**同步；同步失败不阻塞本地使用 |
| F4 | 全局热键唤出底部面板 | 任意应用中唤出；面板横贯当前屏幕底部；**不抢夺当前应用焦点**；再次按快捷键或 Esc 收起 |
| F5 | 历史浏览 | 卡片横向排列，最新在前；显示内容预览、来源 App、相对时间；支持方向键浏览 |
| F6 | 粘贴 | 选中后 Return / 双击：有辅助功能权限则直接插入光标处；无权限则写回剪贴板并提示手动 ⌘V |
| F7 | 搜索 | 面板内输入即过滤（文本内容匹配），清空搜索恢复完整列表 |
| F8 | Pinboard（单收藏夹） | 可将条目固定/取消固定；固定条目独立分区展示，不被自动清理 |
| F9 | 排除应用列表 | 可添加/移除 Bundle ID；被排除应用的复制不进入历史 |
| F10 | 敏感内容跳过 | 遵守 `org.nspasteboard.ConcealedType` / `TransientType` 标记，不记录 |
| F11 | 菜单栏入口 | 常驻菜单栏图标：打开面板、暂停/恢复捕获、退出 |
| F12 | 历史保留设置 | 可配置条数上限与保留时长（默认不限时长） |

## 4. 明确不做（MVP 非目标）

- Paste Stack（顺序粘贴）、多选批量粘贴、粘贴前编辑、纯文本粘贴快捷键
- 多 Pinboard、Pinboard 分享
- iOS / iPadOS 客户端（数据模型预留来源设备字段即可）
- AI 功能（语义搜索、自动分类、MCP 接口）
- OCR、文件内容索引
- 登录/账号体系、遥测、崩溃上报

## 5. 非功能需求

| 项 | 指标 |
|---|---|
| 常驻内存 | 空闲 < 100 MB（目标，非硬门槛） |
| CPU | 空闲轮询下接近 0；无后台高频任务 |
| 面板性能 | 1000 条历史下滚动流畅（懒加载 + 缩略图异步解码） |
| 隐私 | 无任何第三方服务器；同步仅经用户私有 iCloud；无遥测 |
| 可维护性 | 模块边界见 `ARCHITECTURE.md`，UI 与核心逻辑解耦 |

## 6. 用户故事（验收时的操作脚本）

1. 在 Safari 复制一段文字、在备忘录复制一张图片 → 全局热键 → 两条记录按时间倒序出现，来源图标正确。
2. 方向键选中第一条 → Return → 内容直接粘贴进 Safari 当前输入框。
3. 面板中输入关键词 → 列表实时过滤 → Esc 清空/收起。
4. 把某条固定到 Pinboard → 清空历史（设置内操作）→ 固定项仍在。
5. 把 1Password 加入排除列表 → 在 1Password 中复制 → 历史无新增。
6. 菜单栏选择“暂停捕获” → 复制若干内容 → 无新增；恢复后正常。
7. 第二台 Mac 登录同一 iCloud → 历史与 Pinboard 最终一致。
