# P's Paste — UI / 交互规格

> 原则：**交互行为稳定，视觉皮肤可替换**。MVP 借鉴 Paste 的底部面板交互，
> 商业化前视觉需重新设计，因此所有颜色、字号、圆角、间距集中在 `Theme/` 中，
> 视图组件不得硬编码样式值。

## 1. 界面构成总览

| 界面 | 形态 |
|---|---|
| 历史面板（主界面） | 全局热键唤出的底部 NSPanel，非激活窗口 |
| 菜单栏菜单 | 菜单栏图标下拉菜单 |
| 设置窗口 | 标准 macOS 设置窗口（SwiftUI Settings 场景） |

## 2. 历史面板

### 2.1 布局（自上而下）

```
┌──────────────────────────────────────────────────────────────┐
│ [搜索框……………………………………]                    [Pinboard] [设置] │  ← 顶栏，高 ~40pt
├──────────────────────────────────────────────────────────────┤
│ Pinboard 分区（仅在有固定项时出现，横向滚动，最多一行）           │
├──────────────────────────────────────────────────────────────┤
│ ┌────────┐ ┌────────┐ ┌────────┐ ┌────────┐                  │
│ │ 卡片    │ │ 卡片    │ │ 卡片    │ │ 卡片    │  → 横向滚动     │  ← 历史区，最新在最左
│ │ 内容预览│ │        │ │        │ │        │                  │
│ │         │ │        │ │        │ │        │                  │
│ │ [App] 5m│ │        │ │        │ │        │  ← 底部元信息行    │
│ └────────┘ └────────┘ └────────┘ └────────┘                  │
└──────────────────────────────────────────────────────────────┘
  ▲ 面板横贯当前屏幕底部，默认高 ~320pt；上边缘可拖拽调高（可延后到 V2）
```

### 2.2 卡片

- 尺寸：宽约 220–280pt（按内容类型可等宽），高度撑满历史区。
- 内容预览：
  - 文本/链接：多行显示，行上限 8 行（2026-10-29 修订，原 6 行）；超过
    字符预算（300 字）时**中间截断**为「头 70% … 尾 30%」（2026-10-29
    修订，原实现只取第一行 + 尾部截断，长文几乎不可读）；截断规则抽
    纯函数可测。链接额外显示域名。
  - 图片：缩略图等比填充；解码失败回退文本摘要（任务八 D）。
- 元信息行：来源 App 图标 + **copy 发生时刻的静态时间**（今天 `HH:mm`，
  更早 `MM-dd HH:mm`；2026-10-29 修订——原 `.relative` 活体标签会周期性
  自动刷新，导致卡片区无意义的定时重渲染，且不满足"不精确到分以下"的
  期望）。
- 状态：选中态（§5.1 v4：accent 描边 + 纯白卡 + 轻投影）、固定标记（📌）。
- 右键菜单：粘贴、固定/取消固定、复制（不写回历史）、删除。

### 2.3 交互与快捷键

| 操作 | 行为 |
|---|---|
| ⌘⇧`（全局，当前默认） | 唤出面板；面板已显示则收起 |
| Esc | 有搜索文本则先清空搜索，否则收起面板 |
| 点击面板外区域 / 切到其他应用 | 面板自动收起（任务五；非激活面板无失去焦点通知，实现见任务单） |
| ← / → | 移动选中卡片（自动滚动到可见） |
| Return / 双击 | 粘贴选中项（行为见 ARCHITECTURE §7） |
| 输入字符 | 搜索框未聚焦时，按字符键自动聚焦搜索框并填入该字符（输入即过滤） |
| ⌘F | 聚焦搜索框 |
| ⌘, | 打开设置 |
| 拖拽卡片到外部 App | 拖拽粘贴（V2，可延后） |

- 面板**始终不激活 App**，键盘事件由 NSPanel 自行接收。
- 唤出时默认无选中（2026-10-29 修订 v3）：Return 在选中前不粘贴任何东西；
  ←/→ 或点击才选中（无选中时按方向键落到最新一条）。搜索过滤时选中保留则不动、
  失效则落到第一条结果，保证输入后 Return 永远有目标。
- **搜索默认折叠为按钮态**（2026-10-29 修订，任务七；原 icon 态输入框仍直接呈现
  输入框）：每次唤起面板，顶栏搜索位都是放大镜按钮，无文本光标；点击按钮、
  键入可打印字符或按 ⌘F 才展开输入框并进入输入态（输入即过滤）。
  ←/→/Return/Esc 不依赖搜索框聚焦即可用。
- 空状态：显示“复制一些内容试试”与快捷键提示。
- 无辅助功能权限时，顶栏显示“已复制，按 ⌘V 粘贴”式提示条（粘贴后短暂出现）。

## 5. MVP 视觉基调（临时皮肤，非最终设计）

- 深色/浅色跟随系统；**面板底色随当前主题**（§5.2：Parchment 实色暖纸调 /
  Particle 冷灰白，2026-10-29 起双主题）。
- 圆角卡片、系统字体、克制的阴影；动画 < 200ms（唤出/收起轻微上滑 + 淡入）。
- 全部样式常量定义于 `Theme/`，禁止散落魔数。

## 5.1 卡片选中态与配色（2026-10-29 修订 v4，以 Apple HIG 为准绳）

> v4 修订原因（同日用户实测 + 决策）：v3 材质路线实测失效——面板底是不透明
> 实色，`.regularMaterial` 底下没有可模糊的内容，选中卡与未选中卡都呈近白色，
> 1.02 缩放肉眼不可辨，唯一区分只剩 1pt 细描边。用户从三个候选方案中选定
> **C：accent 描边 + 纯白卡 + 轻投影**。v3 及以下历史方案（材质选中 / accent
> 高亮 / 墨蓝描边）全部废弃存档，不再实现；暖色品牌调保留在面板底与暖灰文字上。

目标：选中态一眼可辨（描边 + 明度差 + 投影三重 cue）；卡片与面板背景有明确
层次；深浅色、增强对比度设置下都必须成立（HIG color.md）。

- **选中态（v4 核心）**：选中卡 = **纯白实色**（浅 `#FFFFFF`；深色模式抬亮一档
  的暖白 `#E8E4DC`，判断值）+ **系统 accent 色 2pt 描边**（`Color.accentColor`，
  自动跟随用户系统强调色、深浅色自适应）+ **克制投影**（shadow radius ≈ 8、
  y ≈ 3、不透明度 ≈ 0.15，判断值，具体进 Theme 调）。**无填充、无缩放**——
  投影承担"浮起"深度，缩放 1.02 实测不可辨且引起相邻卡片重排观感，删除。
- **未选中态**：维持 v3 半透明 tint（浅 白 50% / 深 白 10%）+ 1pt 暖灰描边
  （浅 `#E3E0D4` / 深 `#453E35`）。未选中的"灰感"与选中的"纯白 + 彩环 + 投影"
  形成明度、色彩、深度三个可辨维度。
- **层次（浅色）**：面板底暖纸调 `#F0EEE6` → 半透明卡片浮起 → 选中卡纯白 +
  accent 描边 + 投影。面板与卡片必须肉眼可辨。
- **层次（深色）**：面板底 `#1F1C19` → 半透明卡片（白 10%）→ 选中卡 `#E8E4DC`
  暖白 + accent 描边 + 投影。
- **面板底实现**：维持任务七决策——实色不用毛玻璃（半透明会冲淡暖纸调）。
  实色与 HIG materials 不冲突：HIG 允许自定义色替代材质，前提是层次成立。
- **文字色**：主内容用系统 label 色（近黑/近白）；弱化文字/图标（来源 App、
  时间、搜索提示）保持黄棕底调暖灰（浅 `#6E6759` / 深 `#A8A091`），语义上等同
  `.secondary` 层级，对比度须 ≥ 4.5:1。
- **间距（HIG 8pt 网格）**：卡片内边距 12；卡片间距 14；
  内容区与 meta 行的结构保持（内容顶对齐、meta 贴底），但内容首行与卡片顶、
  meta 行与卡片底的内边距必须等于卡片 padding，杜绝"顶边贴字、底部死空白
  不成比例"。卡片行在内容区垂直居中，与顶部分隔线、面板底边各留 14pt
  （`Theme.Card.verticalMargin`），不得贴边。
- **禁用项**：不得引入渐变和重投影；内容层不得使用 Liquid Glass。
- 所有色值、线宽、圆角、间距、投影参数进 `Theme/Theme.swift`，命名带语义，
  视图无魔数。

## 5.2 主题系统（2026-10-29 新增，双主题）

> 来源：用户提交 `Docs/UI_新设计.md`（基于 particle.ai 设计语言的设计系统），
> review 后采纳其 Token 体系与选中样式为第二主题；其"竖列表 HUD 面板"布局
> 不采纳（与底部横滑卡片面板是两种产品形态，属 V2 级决策）。原文档修正：
> 深色 accent 由 `#3B82F6` 改为 `#2563EB`（白字对比度 3.7:1 → 5.15:1）。

- **主题清单**：
  | 主题 ID | 名称 | 定位 | 默认 |
  |---|---|---|---|
  | `parchment` | Parchment（暖纸） | §5.1 v4 现状，品牌暖色调 | ✅ 默认 |
  | `particle` | Particle（冷蓝） | `UI_新设计.md` Token 体系，macOS 正统 accent 实底选中 | 可切换 |
- **架构**：Theme 从静态 enum 升级为协议 + 实例（如 `Theme` protocol，
  `ParchmentTheme` / `ParticleTheme` 实现），经 environment 注入视图；
  `ThemeManager`（`@AppStorage("selectedTheme")`）持有当前主题并持久化——
  是 M2 设置窗口的前置。
- **Particle 主题 Token**（深色/浅色，源自 `UI_新设计.md` §一，已修正）：
  - accent `#2563EB`（深浅通用）；accentSoft = accent 15%/10% 不透明度
  - 背景三级：浅 `#FFFFFF` / `#F9FAFB` / `#F3F4F6`，深 `#0B0F17` / `#111827` / `#1F2937`
  - 文字三级：浅 `#111827` / `#4B5563` / `#9CA3AF`，深 `#F9FAFB` / `#9CA3AF` / `#6B7280`
  - 边框：浅 `#E5E7EB` / 深 `#374151`；语义色 success/warning/danger 暂存不用
  - 字号：body 13 / caption 11 / heading 15 / title 17（code 等宽 12 备用）
  - 圆角：卡片 8、面板 12（控件 6 备用）；网格 8px 基准（与 §5.1 一致）
- **Particle 主题下选中态（核心差异）**：选中卡 = **accent 实底填充 + 白色
  文字/图标**（图片内容不受影响，浮在 accent 底上；meta 行文字转白，
  白 on `#2563EB` ≈ 5.15:1 达标）。无描边、无投影——accent 实底本身即可辨。
  这是 HIG focus-and-selection 的 macOS 集合选中惯例。
- **切换入口**：面板顶栏新增主题按钮（paintbrush SF Symbol），点击弹出
  菜单列出全部主题（Checkmark 标记当前项）选择；切换即时生效并持久化，
  下次启动保持。
- **两主题的公共不变量**：卡片布局、间距（§5.1）、字体语义层级、深浅色
  跟随、选中当帧切换的性能约束（任务六）——主题只换色值与选中绘制策略。
