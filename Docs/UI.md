# P's Paste — UI / 交互规格

> 原则：**交互行为稳定，视觉皮肤可替换**。MVP 借鉴 Paste 的底部面板交互，
> 商业化前视觉需重新设计，因此所有颜色、字号、圆角、间距集中在 `Theme/` 中，
> 视图组件不得硬编码样式值。

## 1. 界面构成总览

| 界面 | 形态 |
|---|---|
| 历史面板（主界面） | 全局热键唤出的底部 NSPanel，非激活窗口 |
| 菜单栏菜单 | 菜单栏图标下拉菜单 |
| 设置窗口 | 标准 macOS 设置窗口（SwiftUI Settings 场景） |

## 2. 历史面板

### 2.1 布局（自上而下）

```
┌──────────────────────────────────────────────────────────────┐
│ [搜索框……………………………………]                    [Pinboard] [设置] │  ← 顶栏，高 ~40pt
├──────────────────────────────────────────────────────────────┤
│ Pinboard 分区（仅在有固定项时出现，横向滚动，最多一行）           │
├──────────────────────────────────────────────────────────────┤
│ ┌────────┐ ┌────────┐ ┌────────┐ ┌────────┐                  │
│ │ 卡片    │ │ 卡片    │ │ 卡片    │ │ 卡片    │  → 横向滚动     │  ← 历史区，最新在最左
│ │ 内容预览│ │        │ │        │ │        │                  │
│ │         │ │        │ │        │ │        │                  │
│ │ [App] 5m│ │        │ │        │ │        │  ← 底部元信息行    │
│ └────────┘ └────────┘ └────────┘ └────────┘                  │
└──────────────────────────────────────────────────────────────┘
  ▲ 面板横贯当前屏幕底部，默认高 ~320pt；上边缘可拖拽调高（可延后到 V2）
```

### 2.2 卡片

- 尺寸：宽约 220–280pt（按内容类型可等宽），高度撑满历史区。
- 内容预览：
  - 文本/链接：多行截断显示；链接额外显示域名。
  - 图片：缩略图等比填充。
- 元信息行：来源 App 图标 + 相对时间（“刚刚 / 5 分钟前 / 昨天 / 日期”）。
- 状态：选中态（高亮描边 + 轻微放大）、固定标记（📌）。
- 右键菜单：粘贴、固定/取消固定、复制（不写回历史）、删除。

### 2.3 交互与快捷键

| 操作 | 行为 |
|---|---|
| ⌘⇧`（全局，当前默认） | 唤出面板；面板已显示则收起 |
| Esc | 有搜索文本则先清空搜索，否则收起面板 |
| 点击面板外区域 / 切到其他应用 | 面板自动收起（任务五；非激活面板无失去焦点通知，实现见任务单） |
| ← / → | 移动选中卡片（自动滚动到可见） |
| Return / 双击 | 粘贴选中项（行为见 ARCHITECTURE §7） |
| 输入字符 | 搜索框未聚焦时，按字符键自动聚焦搜索框并填入该字符（输入即过滤） |
| ⌘F | 聚焦搜索框 |
| ⌘, | 打开设置 |
| 拖拽卡片到外部 App | 拖拽粘贴（V2，可延后） |

- 面板**始终不激活 App**，键盘事件由 NSPanel 自行接收。
- 唤出时默认选中最新一条；搜索时选中第一条结果。
- **搜索默认折叠为按钮态**（2026-10-29 修订，任务七；原 icon 态输入框仍直接呈现
  输入框）：每次唤起面板，顶栏搜索位都是放大镜按钮，无文本光标；点击按钮、
  键入可打印字符或按 ⌘F 才展开输入框并进入输入态（输入即过滤）。
  ←/→/Return/Esc 不依赖搜索框聚焦即可用。
- 空状态：显示“复制一些内容试试”与快捷键提示。
- 无辅助功能权限时，顶栏显示“已复制，按 ⌘V 粘贴”式提示条（粘贴后短暂出现）。

## 3. 菜单栏菜单

```
打开 P's Paste        ⇧⌘`
─────────────────────
暂停捕获 / 恢复捕获
─────────────────────
设置…                ⌘,
退出 P's Paste       ⌘Q
```

- 暂停捕获时菜单栏图标有明显区分（如斜线或灰化）。

## 4. 设置窗口（Tab 结构）

| Tab | 内容 |
|---|---|
| 通用 | 快捷键修改、开机启动、历史上限（默认 1000）、保留时长 |
| 隐私 | 排除应用列表（添加/移除 Bundle ID，可从运行中 App 选取）、清空历史按钮 |
| 同步 | iCloud 开关、同步状态、iCloud 账户未登录提示 |
| 关于 | 版本、辅助功能权限状态与授权入口 |

## 5. MVP 视觉基调（临时皮肤，非最终设计）

- 深色/浅色跟随系统；面板底为实色暖纸调（§5.1，2026-10-29 起不再用毛玻璃材质）。
- 圆角卡片、系统字体、克制的阴影；动画 < 200ms（唤出/收起轻微上滑 + 淡入）。
- 全部样式常量定义于 `Theme/Theme.swift`，禁止散落魔数。

## 5.1 卡片选中态与配色（2026-10-29 修订 v2，以 Apple HIG 为准绳）

> 修订原因：任务七落地 Kami 主题后实测（用户截图 2026-10-29）发现两个 HIG 层面的问题：
> ① 卡片 `#FAF9F4` 与面板底 `#F5F4ED` 仅差一档明度，未选中卡"和背景一致"；
> ② 选中态 = 2pt 墨蓝描边 + 8% 填充，"不起眼"——macOS 集合类选中惯例是
> **accent 填充高亮**（HIG focus-and-selection：列表/集合用高亮而非细环；
> 选中高亮属 accent 管辖，HIG color.md）。
> 原 Kami 方案（墨蓝描边 / 暖纸三档）**废弃存档，不再实现**；暖色品牌调保留在
> 面板底与卡片底色上，选中态让位给系统惯例。

目标：选中态一眼可辨（accent 高亮）；卡片与面板背景有明确层次；深浅色、
增强对比度设置下都必须成立（HIG color.md）。

- **选中态（核心变更）**：选中卡 = 系统 accent 色 `Color.accentColor`
  （即用户系统设置里的强调色，自动深浅色适配）2pt 描边 +
  accent 约 15% 不透明度填充（比 v1 的 8% 明显一档）+ 轻微放大（≤1.02，保留）。
  废弃自定义墨蓝/钢蓝描边。填充与描边当帧切换、仅缩放保留 0.1s 动画（任务六的
  交互性能约束不变）。
- **层次（浅色）**：面板底暖纸调 **降半档** `#F0EEE6`（原 `#F5F4ED` 与卡片
  太接近）→ 卡片近纯白 `#FFFFFF`、1pt 暖灰描边 `#E3E0D4` 不变 → 选中卡 accent
  高亮。面板与卡片明度差必须肉眼可辨（这是本轮验收重点）。
- **层次（深色）**：面板底 `#1F1C19` → 卡片 `#332E29`（差一档）→ 选中 accent
  高亮（accent 在暗底自动变亮，无需自定义钢蓝）。
- **面板底实现**：维持任务七决策——实色不用毛玻璃（半透明会冲淡暖纸调）。
  实色与 HIG materials 不冲突：HIG 允许自定义色替代材质，前提是层次成立。
- **文字色**：主内容用系统 label 色（近黑/近白）；弱化文字/图标（来源 App、
  时间、搜索提示）保持黄棕底调暖灰（浅 `#6E6759` / 深 `#A8A091`），语义上等同
  `.secondary` 层级，对比度须 ≥ 4.5:1。
- **间距（HIG 8pt 网格）**：卡片内边距 10 → **12**；卡片间距 12 → **14**；
  内容区与 meta 行的结构保持（内容顶对齐、meta 贴底），但内容首行与卡片顶、
  meta 行与卡片底的内边距必须等于卡片 padding，杜绝"顶边贴字、底部死空白
  不成比例"。
- **禁用项**：选中态不得只靠阴影或 1pt 细线区分；不得引入渐变和重投影。
- 所有色值、线宽、圆角、间距进 `Theme/Theme.swift`，命名带语义，视图无魔数。
